# Материалы SC

Репозиторий с материалами.

## Медиафайлы на сервере

Материалы хранятся на нашем сервере в основной папке с настроенным nginx для внешней раздачи.

**Структура на сервере:** `module_N/ex_M/файл` (по модулям → по заданиям).

Пример пути на сервере:
`185.93.109.21:7447/production/kos/moodle_media/module_5/ex_2/correct1.wav`

**Загрузка:** подключение по SFTP → заливка в нужную папку → указание пути в интерактивах.

**URL в заданиях:** папка `kos` — корень для Moodle, но в интерактивах путь указывается так:

```
https://sc-learn.ru/moodle_media/module_5/ex_7/audio_2025-03-11_13-06-19.ogg
```
