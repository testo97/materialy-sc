# Список изображений диалогового тренажёра (module 8 / dialog_train)

Изображения подключаются двумя способами: одно — прямо в `content/index.html` (персонаж Денис),
остальные — как фоновые картинки в `content/css/style.css`. Все файлы лежат на одном хранилище
с базовым адресом:

`https://storage.yandexcloud.net/audio-test-sc/`

Ниже — полный список с расшифрованными именами файлов (в ссылках они URL-закодированы)
и описанием роли каждой картинки.

---

## ⚠️ Важное примечание

В **текущей версии** тренажёра в коде `content/main.js` реально проигрывается только сценарий
с гостем **Алексеем** (`currentDialogue = alexeyDialogue`). Картинки **Галины** и
**Тамары Ивановны** прописаны в CSS как заготовки для других гостей, но ни один скрипт их
не подключает — то есть в работающем интерактиве они сейчас **не отображаются**.
